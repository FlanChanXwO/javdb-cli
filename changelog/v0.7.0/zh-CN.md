## 新增

- 新增以图搜番：接受本地路径、HTTP(S) URL 或二进制 stdin 的 JPEG/PNG/WEBP 图片（最大 8 MiB）；把原始字节上传到内置 AVScan provider 或声明式外部 HTTP source；返回规范化候选与帧；并以大小写不敏感的严格番号精确匹配把每个候选联动到完整 JavDB 详情。响应按 source 与原图 SHA-256 本地缓存 30 天，`javdb cache reverse-search` 只查看或清理该缓存。 评审后加固同时覆盖 mark 状态语义、本地命令的 JSON 输出、缓存损坏处理与敏感 header 校验。 ([`26f07f7`](https://github.com/FlanChanXwO/javdb-cli/commit/26f07f762e42d7321448e616f4b0ab2cee6a032a), [`51aabdc`](https://github.com/FlanChanXwO/javdb-cli/commit/51aabdc6dbd0eb87c994ae8737d28f678815273d), [`62ba4ab`](https://github.com/FlanChanXwO/javdb-cli/commit/62ba4ab19a9a9f9944673113d32671f8461e6cce), [`65d493b`](https://github.com/FlanChanXwO/javdb-cli/commit/65d493b47d2ecda1c53a1e566370eaa5dc8915bc), [`883a066`](https://github.com/FlanChanXwO/javdb-cli/commit/883a06698bbdbb28fc34fc4be0397a6edcc2ec14), [`a2844e3`](https://github.com/FlanChanXwO/javdb-cli/commit/a2844e3402b3e999c17bbeaa8cfed55731d9023d), [`a35ff17`](https://github.com/FlanChanXwO/javdb-cli/commit/a35ff17493366d46320f0f54d09d422ff734690d), [`b46c096`](https://github.com/FlanChanXwO/javdb-cli/commit/b46c096b1dd834bf1cfeeb65a888cf658f4c072c), [`b8df453`](https://github.com/FlanChanXwO/javdb-cli/commit/b8df4539684ee3bdb4e4b4b84cf2f65a1fb4b72c), [`c324b9b`](https://github.com/FlanChanXwO/javdb-cli/commit/c324b9bffe8db6c6f9a16f61a08d7c6a7b40d1ad), [`d16b546`](https://github.com/FlanChanXwO/javdb-cli/commit/d16b546e61efd718ea6f247d4943aa33387fb7c7), [`d204300`](https://github.com/FlanChanXwO/javdb-cli/commit/d204300fb30f19aa5ada461b558151c22ebd6027), [`d7ccdbe`](https://github.com/FlanChanXwO/javdb-cli/commit/d7ccdbe21e4916fcf7bc2f9eecb6cb6f090e8acb), [`e7a37de`](https://github.com/FlanChanXwO/javdb-cli/commit/e7a37de40b1c1690e5c4902331ac8aeb41f977e2), [`f5a5c72`](https://github.com/FlanChanXwO/javdb-cli/commit/f5a5c72046205146fb0e9632cf2ff47559ceb031), [`fb63f1d`](https://github.com/FlanChanXwO/javdb-cli/commit/fb63f1df2d940dd3a3dd67f6bc5cacd5f9362408), [#24](https://github.com/FlanChanXwO/javdb-cli/pull/24))
